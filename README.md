# Co-Simulation Scenario Library

This repository collects co-simulation scenarios from scientific publications, with a focus on mosaik. The catalogue currently focuses on Level 1 scenario overviews. Each overview summarizes what the scenario investigates, which components participate, and where to find the original sources.

[Browse the scenario overview](catalogue/overview.md)

## Repository structure

- `catalogue/` — Scenario overview and CSV index
- `scenarios/` — Individual scenario records
- `publications/` — Publication records
- `models/` and `software/` — Model and software records
- `evidence/` — Source references and supporting evidence
- `docs/` and `reviews/` — Collection documentation and scenario reviews
- `schemas/`, `tools/`, and `tests/` — Record schemas, scripts, and tests
