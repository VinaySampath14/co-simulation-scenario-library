# Local process-aware monitoring of a distribution substation

Evaluates whether a local monitor can recognize unsafe or inconsistent operation by checking SCADA information against the physical behaviour of a distribution grid.

The testbed combines PYPOWER, household load and PV inputs, a simulated remote terminal unit, a SCADA server and a local monitoring device. The paper studies local monitoring of a field station. This is the earlier testbed in the research lineage of the later two-subgrid monitoring study. [PDF pp. 11–14, implementation sections and Figures 3–4](https://doi.org/10.1186/s42162-018-0058-7)

The earlier paper describes a mosaik testbed for process-aware local monitoring using simulated grid measurements and remote terminal units. The earlier setup is preserved as a related study of the testbed lineage. [Earlier paper](https://doi.org/10.1109/SmartGridComm.2017.8340672)
