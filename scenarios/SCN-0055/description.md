# Uncertainty propagation in an eight-node residential PV grid

Uses a mosaik residential PV grid to study how uncertain inputs and model outputs affect photovoltaic production and feeder power flow.

The eight-node PYPOWER grid is coupled to household consumption data, photovoltaic panel models and irradiance data. The probabilistic study evaluates ensemble-based propagation. An earlier related study uses the same component pattern to examine uncertainty bounds. [PDF pp. 4–5, Section V and Figures 2 and 5](https://doi.org/10.1109/MSCPES.2016.7480222)
