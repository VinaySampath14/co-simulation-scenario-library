# Industrial hybrid power system sizing and voltage assessment

Max Deutman's 2023 thesis uses mosaik to couple an industrial load with a photovoltaic production profile, a battery, a diesel generator and an energy management system. The controller uses a rolling average to limit changes in the site's draw from the grid. The study uses NSGA-II to compare component sizes under four controller configurations, using cost and CO2 emissions as objectives. [Thesis, Sections 3.1–3.2](https://repository.tudelft.nl/file/File_973b6cef-969f-48d9-90d3-8010d66dd34d) · [Companion paper, Sections II–III](https://repository.tudelft.nl/file/File_90e2976c-c66e-467a-a029-7effce866051)

The resulting grid demand profile is used in a subsequent steady-state load-flow analysis of the CIGRE medium-voltage distribution network in pandapower. The thesis reports about 47% lower CO2 emissions for the selected configuration relative to direct grid supply and reports no worsening in the voltage behaviour considered. [Thesis, Sections 3.3 and 4.2](https://resolver.tudelft.nl/uuid:67428726-21d0-4ef7-83bf-fc26bde07ff7) · [Companion paper, Section IV](https://repository.tudelft.nl/file/File_90e2976c-c66e-467a-a029-7effce866051)

The main starting point is Section 3.1.1, “Mosaik,” on printed page 9. Sections 3.1.2–3.1.6 describe the components. Appendix A, starting on printed page 52, contains selected Python listings.
