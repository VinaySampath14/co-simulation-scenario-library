# Distribution-grid tap control and state estimation with simulated communications

Evaluates mosaik co-simulation scheduling for two smart-grid applications, transformer tap control and distributed state estimation.

The thesis couples OpenDSS and ns-3 with Python control, state-estimation and collection components. The two applications share the grid and communications simulation architecture and are evaluated as examples in Chapter 5.
