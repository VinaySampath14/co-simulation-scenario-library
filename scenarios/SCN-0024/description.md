# Large electrolyser connection in an urban medium-voltage grid

Evaluates connecting a large electrolyser to an urban SimBench medium-voltage grid. The mosaik showcase investigates bus voltage limits and includes an analysis of electrolyser degradation.

The medium-voltage showcase first screens grid buses for steady-state voltage constraints and then studies the effect of a large electrolyser on the selected network. This case uses the same toolbox as the extra-high-voltage congestion showcase.

The record is based on the PDF attached in Zotero.
