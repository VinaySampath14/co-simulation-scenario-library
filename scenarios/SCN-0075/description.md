# Smart Nord EV charging control for local PV surplus

Demonstrates a synchronized mosaik controller that starts or stops EV charging in response to electricity export from a Smart Nord feeder.

Schütte simulated one Smart Nord low-voltage grid and used a controller to switch EV charging based on power flow at the feeder’s slack node. The experiment evaluates synchronization and data access through the mosaik ControlAPI. It shares the Smart Nord project with SCN-0060, whose experiment compares measured PV profiles with FMI models. [Source, Section 12.5.1, printed pp. 273–274](https://oops.uni-oldenburg.de/1768/1/schsim13.pdf)
