# Scalability of multi-agent control in cellular power grids

Benchmarks the execution time of a mosaik-based cellular grid simulation as the number of cells and the depth of the agent hierarchy change.

The authors use a benchmark derived from the European medium-voltage distribution network and couple it to MASSCA's mango-based multi-agent simulator. The experiments measure total scenario runtime and agent interaction time for different cell counts and hierarchy depths. [Printed pp. 363–367, simulation setup and scalability experiments](https://doi.org/10.5281/zenodo.14004357)
