# Power-flow surrogate training on a MIDAS medium-voltage benchmark

Uses MIDAS and mosaik to compare sampling methods and evaluate whether data-driven models can replace a medium-voltage power-flow model.

The study trains surrogate models using an urban SimBench network and compares their predictions with the original model. It also profiles a CIGRE grid with explicit distributed energy resources alongside the SimBench configuration as a runtime comparison.
