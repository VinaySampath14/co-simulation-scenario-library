# Same-time feedback between a master controller and local agents

Demonstrates how a master controller and local controllers exchange feedback within the same mosaik simulation time before model states advance.

The conference paper introduces same-time feedback and links the tutorial. The versioned tutorial implements the demonstration with synthetic state models, local controllers and a master controller. It includes scenario code and collector output. [Paper](https://arxiv.org/html/2410.16937v1) · [Code](https://mosaik.readthedocs.io/en/3.3.2/tutorials/sametimeloops.html)
