# mosaik demo-derived comparison of household demand with PV and EVs

Uses a mosaik demo-derived grid to compare household demand with configurations that add PV and EVs.

The report uses household profiles, PV time series, PYPOWER, HDF5 and web output. Chapter 5 introduces PV and EVs to examine changes in active power. [PDF pp. 45–49, Chapter 5 and Figures 5.1–5.5](https://www.zotero.org/groups/5844550/items/3VYZZZFT)
