# Active-power coordination by PV and household agents over simulated communications

Uses mosaik and cosima to study how communication affects a group of agents coordinating an active-power contribution.

The authors implemented a simplified COHDA-inspired experiment. Each agent receives data from PV and household simulators. The communication variants compare direct exchange, simulated Ethernet and LTE delivery, and a case with one agent becoming unavailable. This evaluates cooperative power coordination, alongside a separate scheduling-speed study covered by SCN-0044.
