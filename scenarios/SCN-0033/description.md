# Hybrid real-time voltage control with a grid-connected building

Tests low-voltage control in a hybrid mosaik and OPAL-RT setup by comparing operation with the voltage controller enabled and disabled.

The real-time simulator hosts the grid, grid loads, PV, battery and building energy management. Mosaik coordinates software models for household behaviour, rooftop PV, weather, the building envelope, voltage control, and the heat pump and its controller.
