# Island-grid diesel dispatch with IPSYS and agent controllers

Compares two mosaik couplings against an IPSYS baseline for dispatching diesel generators in a three-bus island grid.

Figure 9 identifies the wind turbines, diesel generators, residential load and dump load. The experiments replace the controller implementation with MasSim or JadeSim while using IPSYS-DE for the power system. [PDF pp. 6–7, experiments and Figures 9–11](https://doi.org/10.1109/PSCC.2014.7038479)
