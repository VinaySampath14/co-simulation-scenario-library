# eELib low-voltage prosumer grid with battery surplus control

Demonstrates a mosaik low-voltage grid scenario with multiple prosumer buildings and a simple surplus-based battery strategy.

The grid case uses pandapower and lower-detail household device representations. Home energy management charges batteries when generation exceeds consumption and discharges them when demand exceeds local generation. The paper provides per-building parameters and reports grid-scenario results separately from the single-building case.
