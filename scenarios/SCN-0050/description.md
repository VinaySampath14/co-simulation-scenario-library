# Power restoration with communications backup in a distribution grid

Studies how communication coverage and backup power affect the amount of electrical load restored after an outage.

Mosaik couples a SimBench grid, mango restoration agents and a NetworkX communications model. The study compares communications cell sizes and battery backup availability, using restored electrical load as the evaluation measure.
