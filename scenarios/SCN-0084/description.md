# GridEVA residential district with simulated communication delays and failures

Examines how communication delays and failures affect a residential power system with high electric vehicle and renewable generation penetration.

The district configuration extends the GridEVA power components with cosima communication and reports network monitoring and grid snapshots. It shares the GridEVA lineage with SCN-0020, whose focus is EV hosting capacity. The repository credits OFFIS developers.
