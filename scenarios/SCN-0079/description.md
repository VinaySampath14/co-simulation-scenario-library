# Quantum and classical power flow in a five-bus grid

Compares classical power flow, simulated quantum computation, and real quantum hardware in a mosaik grid experiment that curtails photovoltaic output when a line overloads.

The authors couple power flow with a solar generation profile, aggregate loads, a balancing generator and a line monitor on a simplified five-bus system. They compare curtailment behavior across the three solver configurations. The paper links the repository containing scenario.py, simulation.py, data and analysis files.
