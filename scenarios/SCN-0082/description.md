# Modular vehicle production with RAMI 4.0 and mosaik

Demonstrates the use of mosaik to evaluate how modular automotive production units interact and how their workloads change during a production run.

The study models car bodies moving among production islands. It reports station occupancy and processing durations across ten runs. The RAMI project page offers a Python project archive whose contents could not be checked.
