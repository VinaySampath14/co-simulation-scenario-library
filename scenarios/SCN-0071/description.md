# Fallback voltage control for residential PV in an active distribution grid

Compares normal and fallback voltage regulation for a residential PV demand-side management system when communications are disrupted.

The study uses mosaik 3 to join a SimBench low-voltage grid, pandapower load flow, smart homes and a distribution system operator model. The comparison evaluates a fallback mechanism for maintaining grid operation. The paper states that its data cannot be shared.
