# Small GridEVA–cosima power and communications coupling test

Demonstrates technical coupling between a small power system and a simulated communications network before applying the setup to a residential district.

The ZDIN-ZLE project supplies a small proof of concept that couples GridEVA power components with cosima and OMNeT++ using mosaik. The project documents separate communication and grid checks.
