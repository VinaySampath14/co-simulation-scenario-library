# Electricity and heat coupling in a low-temperature anergy network

Demonstrates how a low-temperature thermal network and an electricity grid can be co-simulated in mosaik using an illustrative district with buildings and a data center.

Apartment buildings draw heat through heat pumps. A data center contributes waste heat while requiring electricity and cooling. PV supplies the data center, and a power-to-heat unit can use surplus electricity. The paper describes a PYPOWER interface for the electricity network.

The record is based on the PDF attached in Zotero. [PDF pages 2–3, scenario and implementation description](https://doi.org/10.1109/GreenTech62170.2025.10977582) The published code revision remains unverified. [Repository](https://github.com/DominikVereno/anergy-network-co-simulation)
