# PAVN distributed virtual power plant and grid coordination

Demonstrates how mosaik couples distributed simulation tools to evaluate the coordination of virtual power plant schedules with distribution-grid limits.

The PAVN scenario connects a virtual power plant simulator, a power system simulation tool and a communication and service platform. The virtual power plant computes generation and consumption schedules, the power system tool evaluates grid restrictions, and the service platform represents coordination between participating organizations.
