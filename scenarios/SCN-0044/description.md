# Event-based communication benchmark with photovoltaic agents

Uses mosaik and OMNeT++ to compare time-based and event-based scheduling for communicating agents paired with photovoltaic systems.

The baseline has five agents, each attached to a PV system. OMNeT++ models delivery of messages between the agents. A larger-network experiment varies agent count to assess how simulation runtime and the number of steps scale. [PDF pp. 6–7, Section 4 and Figures 3–6](https://doi.org/10.48550/arXiv.2209.12550)
