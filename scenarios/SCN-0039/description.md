# Comparing modular agent-based voltage control on a distribution grid

Compares two agent-based voltage-control concepts and a recombination of them on a distribution grid. The mosaik study tests how each controller resolves voltage-limit violations across four operating cases.

Mosaik coordinates pandapower power-flow calculations and voltage-control agents implemented with aiomas. The agents use distributed generator reactive power and an on-load tap-changing transformer to regulate voltages. The four test cases vary the location and direction of the voltage deviation and the flexibility available to the controller.
