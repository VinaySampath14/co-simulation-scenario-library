# Energy Hub Gas multi-carrier conversion co-simulation

Evaluates whether the same Energy Hub Gas concept can be implemented consistently with mosaik and PROOF.

The study represents a neighborhood-scale application with coupled energy carriers and uses an electrolyser as a documented example of component integration. The authors report matching results for the mosaik and PROOF implementations of the use case. [PDF pp. 3–6, Sections III?V and Table 1](https://doi.org/10.1145/3470481.3472712)
