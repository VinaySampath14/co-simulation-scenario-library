# Moving cloud and photovoltaic output in a low-voltage grid

Demonstrates spatial matching of PV panels to simulated irradiance cells and shows how a moving cloud changes PV output.

The thesis connects six PV systems to a mock low-voltage grid. Grid node positions determine which irradiance cells supply each PV model. Figure 12.15 shows the resulting feed-in changes. [Thesis, Section 12.4.2 and Appendix J.2](https://oops.uni-oldenburg.de/1768/1/schsim13.pdf)
