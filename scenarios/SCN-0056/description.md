# MoReSQUE uncertainty propagation on a 37-node PV feeder

Evaluates the MoReSQUE uncertainty quantification prototype in a mosaik feeder case with 37 nodes.

The low-voltage network has four branches, with one household and one PV unit at each node. The evaluation propagates probability distributions for uncertain weather, consumption and model inputs and examines the resulting output uncertainty.
