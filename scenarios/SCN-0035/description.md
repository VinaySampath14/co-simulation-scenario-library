# Communication effects on distributed CHP scheduling with cosima-mango

Compares ideal communication with simulated network delivery in a distributed CHP scheduling experiment built on mosaik.

Mango agents use the COHDA heuristic to coordinate CHP plants with different sizes and initial states. Cosima couples the agents to OMNeT++ so the study can measure how network delivery affects negotiation time. The paper also reports an impaired-communication comparison. [PDF pp. 3–4, experiment discussion and Table 1](https://doi.org/10.1016/j.softx.2024.101667)
