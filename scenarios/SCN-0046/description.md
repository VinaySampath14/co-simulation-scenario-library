# Adaptive state estimation from live distribution-grid simulation data

Evaluates whether the Odysseus stream-processing system can estimate grid state from live mosaik data and how processing changes with the grid configuration.

The thesis uses a small radial feeder with four nodes and a larger 37-node configuration based on the mosaik demo. Simulated electrical values feed the Odysseus estimator and provide a reference for checking its results. The thesis title page dates the work to 2016. [PDF pp. 79–89, Chapter 5 and Figures 5.1–5.2](http://mosaik.offis.de/downloads/AdaptiveStateEstimationInOdysseus.pdf)
