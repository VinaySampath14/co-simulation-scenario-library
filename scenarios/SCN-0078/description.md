# Hierarchical grid composition and scaling benchmark

Demonstrates automatic composition of nested medium- and low-voltage grids and measures how composition time changes with the number of feeders and nodes.

The example connects household profiles, PV models and EV models to a nested grid. The thesis reuses this setup for the benchmark, varying the number of low-voltage grids and nodes per grid. [Thesis, Sections 12.4.1 and 12.4.5 and Appendix J.1](https://oops.uni-oldenburg.de/1768/1/schsim13.pdf)
